# 'dir' コマンド

- Windows のコマンドプロンプトで使用される、ディレクトリ（フォルダー内のファイルやサブディレクトリを一覧表示するコマンド

- 指定したフォルダー内のファイル名・フォルダー名・サイズ・更新日時 などを一覧表示する

- オプションを付けることで、再帰的表示、並び替え、フィルタリング などが可能

## よく使うオプション

| オプション | 内容 |
| - | - |
| /S | 「全部の階層をまとめて表示」指定フォルダーの中だけでなく、その下にあるサブフォルダーの中身まで 全部まとめて表示する |
| /B | 「名前だけ表示」余計な情報（サイズ・日付など）を全部消して、ファイル名やフォルダー名だけを表示する |
| /A | 「属性で絞り込む」特定の種類だけを表示したいときに使う
例：
	•	/A:D → フォルダーだけ
	•	/A:-D → ファイルだけ
	•	/A:H → 隠しファイルだけ |
